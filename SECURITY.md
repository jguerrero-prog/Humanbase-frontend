# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue. On GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers can see the report.

Include what you found, the page or file it affects, and the steps to reproduce it. You'll get a reply within a week, and we'll agree on a fix and a date before anything is made public.

## What this covers

This repository is the Humanbase front end and its design system. Problems in the Humanbase API, the data it serves or humanbase.io's hosting belong to the Humanbase team; report those through the contact on [humanbase.io](https://humanbase.io).

## Supported versions

Fixes go into the latest release on `master`.
